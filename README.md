# CuinaCatalanaOSM

<p align="center"><img src="logo.png" alt="Logotip de CuinaCatalanaOSM" width="220"></p>

Mapa d’establiments etiquetats amb `cuisine=catalan` a OpenStreetMap. Permet consultar-los, explorar els valors de `cuisine` i detectar possibles errors d’etiquetatge.

**[Obre el mapa](https://atarom.github.io/CuinaCatalanaOSM/)**
